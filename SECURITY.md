# Security policy

TidyShelf moves files on your PC, so safety problems matter a lot. If you find something that could make TidyShelf lose, expose or misplace files, or run something it shouldn't:

1. **Don't open a public issue.**
2. Send the details privately from the [contact page](https://tidy-shelf-official.vercel.app/contact) (choose "Something else" and start the subject with "Security"), or use GitHub's **Report a vulnerability** button on the *Security* tab of this repository.
3. Include the TidyShelf version (Support page), Windows version, and steps to reproduce.

You'll get a reply within a few days. Please give a reasonable time to ship a fix before sharing details publicly.

Supported versions: the latest version in the Microsoft Store.
