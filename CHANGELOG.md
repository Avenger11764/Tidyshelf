# Changelog

Each version here is published as a GitHub release (tag `vX.Y.Z`). TidyShelf reads the latest release to tell you about updates.

## 1.0.3 — October 2026

- TidyShelf now starts quietly in the notification area when you sign in (turn it off in Settings › Startup)
- If Windows doesn't let TidyShelf change start-at-sign-in, a button takes you straight to Windows Startup settings
- Faster archive thumbnails
- Small fixes and improvements

## 1.0.2 — October 2026

- Much smoother: scanning and checking folders no longer freezes the window
- Archive thumbnails load quickly, even while a cleanup is running
- View any archived file larger, and open it in its default app from the Archive
- A start-up screen with the TidyShelf logo while the app opens
- Pro purchases are recognised straight away, and Restore purchases finds them reliably

## 1.0.1 — October 2026

- Report a problem works from the app, with GitHub and save-to-file fallbacks if you're offline
- Your Pro price is shown clearly beside the Buy button
- Website, privacy and support links point to the new site

## 1.0.0 — October 2026

First public release.

- Archive old screenshots and downloads into a local archive you can always restore from
- Preview every move first; undo any run from History
- Space report, duplicate finder and “Kept forever” protection
- Search text inside archived screenshots (Windows OCR, on your PC only)
- Send files by dragging them onto the window
- Long jobs keep running while you switch pages, with progress in the sidebar
- About & Support page: update checks, what’s new, and Report a problem
- TidyShelf Pro: one-time purchase in the Microsoft Store — schedules, custom rules, unlimited folders and drives
